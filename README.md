## ✨ Features

- 🎬 **Typewriter headline** — types and re-types through my role titles on a loop
- 💡 **Glowing, floating profile photo** — pulsing border glow + continuous float animation
- 🔷 **Animated tech badges** — icons around my photo fade in/out and glow on a staggered cycle
- 🃏 **Individually staggered card reveals** — every card slides into view on its own as you scroll, then settles into a gentle idle float with a pulsing glow halo
- 🖱️ **3D hover-tilt cards** — cards tilt toward your cursor on hover
- 🌌 **Live particle network background** — moving, connecting dots across the whole page
- 🧭 **Scroll-spy navigation** — nav pill highlights the section you're currently viewing
- 📊 **Animated stat counters** — numbers count up when scrolled into view
- 📱 **Fully responsive** — works down to mobile, with a slide-out nav menu
- ♿ Accessible focus states, semantic markup, and reduced layout shift

## 🚀 Getting Started

Clone the repo and open it directly — no build tools required.

```bash
git clone https://github.com/Husman325/portfolio.git
cd portfolio
```

Then either:
- double-click `index.html`, or
- open the folder in VS Code and run it with the **Live Server** extension (recommended)

> Requires an internet connection on first load — fonts and icons load from a CDN.
